Команди бота:
- /start — привітальне повідомлення та короткий опис команд бота.
- /help — детальне пояснення, як користуватися ботом.
- /add — користувач надсилає ID або Handle YouTube-каналу та обирає чат, у який бот надсилатиме повідомлення про вихід нових відео.
- /list — виводить список усіх каналів, на які оформлено підписку, із прив'язаними чатами.
- /remove — видалення підписки.
